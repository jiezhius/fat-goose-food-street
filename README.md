# 肥鹅美食街 🦢

一个 HTML5 泡泡龙小游戏，改编自一张小朋友的手绘设定图（`assets/original-drawing.jpg`，标题页点「看看原作」能看）：
最上面是一簇食物（橘子、苹果、西瓜、咖啡、果汁、鹅蛋），后来又添了小鸡、小鱼、小猪；
最下面是扎着高马尾、穿粉裙子的小姑娘，旁边一只小鹅负责上菜，还蹲着猫、兔子、乌龟和一只瓢虫；
中间那条横线是原画里就有的——现在它是**警戒线**，食物压过去就算输。

## 怎么玩

- **电脑**：移动鼠标瞄准（有虚线预览，会算墙壁反弹），点一下发射；方向键微调，空格/回车发射。
- **手机**：按住屏幕拖动瞄准，松手发射。
- 同一种食物**连成 3 个或更多**就会被吃掉；被吃掉后**悬空的那一串会整体掉下来**，额外加分。
- 每隔几发，街上会**上新菜**（顶部多出一行往下压）。把整条街吃光就过关。
- 一共 9 样图案，但**一关最多上 6 样**，而且每关换一批阵容，所以不会一直是同一批面孔。

## 怎么运行

直接双击 `index.html` 就能玩——单文件、零依赖、不联网、离线可用，也可以直接 AirDrop 给家里人。

想用本地服务器（比如在手机上开）：

```bash
python3 -m http.server 4173
```

## 放上原画

原画照片已经在 `assets/original-drawing.jpg` 了。换一张的话注意两件事：

- **要真的把像素转正**。`sips -r 90` 在有 EXIF 的照片上只改元数据、不动像素，浏览器会再转一次，结果是躺着的。
  用 Image Events 才是真转：`osascript -e 'tell application "Image Events" to ...'`（见下），或者干脆转完把 EXIF 的
  orientation 归位成 1。
- 换掉之后不放也不影响游戏，那个页面会显示一句提示。

## 文件

```
index.html   整个游戏（HTML + CSS + JS 全在里面，按功能分了段落注释）
assets/      原画照片放这里
```

代码里几个好改的地方：

| 想改什么 | 去哪儿 |
|---|---|
| 难度曲线（每关几行、几种食物、隔几发上新菜） | `levelConfig()` |
| 食物种类和颜色 | 顶部的 `TYPES` / `TYPE_ORDER`，画法在 `drawOrange` 等函数里 |
| 出手动作的幅度和节奏 | `throwCurve()` 定节奏，`girlTransform()` / `drawGirl()` 定幅度 |
| 出手的亮片和弧光 | `sparkleBurst()`，弧光在 `render()` 里的 `state.swoosh` 那段 |
| 版面尺寸、警戒线、发射点 | 顶部常量 `W/H/R/DANGER_Y/ORIGIN` |
| 手绘笔触的抖动幅度、淡彩浓度 | `roughPath()` / `washFill()` |
| 中英文文案 | `I18N` |
| 小姑娘的裙子 | `drawGirl()` |
| 手的形状 | `drawHand()`——**就三条线**，没有轮廓也没有填充。手在屏幕上不到 20px，画轮廓、填肉色都只会糊成一个团；小孩画手也就是在胳膊末端划拉三下。这里是**故意画得简单**的，别再往上加结构了 |
| 小动物散步的路线和速度 | 顶部的 `STROLL` 常量（每只的起点、走哪边、走多远、速度、走还是蹦），调度在 `updateStroll()` / `strollState()`，画在 `render()` 里的 `strollAt()` |
| 高马尾的形状 | `drawGirl()` 里的 `ctrl`（走向）和 `tailW`（粗细曲线）。`smoothSpine()` 先把控制点插成平滑曲线，`ribbon()` 加粗成发束，`offsetSpine()` 再借同一套法线画里面那几绺散发 |
| 裙子上的"筱"、旁边那句"世界第一漂" | `handwrite()`，调用点分别在 `drawGirl()` 和 `render()` 里 |
| 街边的猫兔龟和瓢虫 | `drawCat/drawRabbit/drawTurtle/drawLadybug`，摆位置在 `render()` 里 |
| 哪一关上哪几样图案 | `levelTypes()` + `TYPE_ORDER` |

## 说明

- 美术全部是用 Canvas 现画的「铅笔线稿 + 淡彩」，包括纸张颗粒和折痕，没有用任何图片素材。
- 淡彩用的是正片叠底，两层色叠上去会变深而不是变灰，蜡笔反复涂就是这个效果。
- `washFill()` 的「涂色出格」偏移量默认 ±3.5px：画 40px 的水果是味道，画 30px 的手就是填充整个跑到轮廓外面。
  画小东西记得把最后那个 `spread` 调小（手用的是 1.6），`roughPath` 的 `amt` 也要一起收着点。
- 六样东西刻意长得都不一样：西瓜是切开的一角（红瓤绿皮黑籽），咖啡带碟子和热气，果汁是紫的还插着红白吸管——
  一屏全是圆球的话，光靠颜色深浅是分不出来的。第一关就上 4 种，不然前两关看着太单调。
- 音效是 WebAudio 现场合成的，没有音频文件。
- 最高分、语言、静音状态存在 localStorage 里。
- 裙子边上那四只（小鹅、猫、兔子、乌龟）会**轮流出来溜达**：一次只有一只在动，从自己的位置走出去再走回来站好，
  然后换下一只；每只速度不一样，出场顺序每轮重新洗牌。路线是照着躲开粉裙子和右下角那三个按钮量出来的，别随手加长。
- 手里那颗食物是**先于**小姑娘画的，这样三条手指线才压得住食物下缘、读起来像捏着。改 `render()` 的顺序时注意别弄反。
- 打开了「减少动态效果」的系统设置时，会自动关掉抖动、碎屑、小动物的起伏和散步。
- 弹框里的按钮：过关是「下一关 / 重玩本关」，输了是「再试一次 / 回首页」，暂停是三个都在。
  （早先输了的时候 `btnRetry` 和 `btnHome` 会同时显示成「回标题」，两个一模一样的按钮，是个 bug。）
